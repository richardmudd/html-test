Page Image Downloader

Enter one or more comic page URLs (one per line) you're authorized to bulk-download from. Each comic's images are pulled into its own folder inside one zip.


How it works / limitations: Browsers can't fetch arbitrary cross-origin pages directly (CORS), so this routes the page HTML and each image through a public CORS proxy (corsproxy.io). That means:
  • It only works on publicly accessible pages — nothing behind a login.
  • Reliability depends on the third-party proxy staying up; if it fails, try again later or swap the PROXY constant in the source for one you trust/control.
  • You are responsible for only using this on pages/images you own or are otherwise authorized to download in bulk. This is a generic tool with no site-specific logic.
